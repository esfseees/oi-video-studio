# 信奥讲解视频工坊

输入一道信奥题和答案代码，自动生成带配音的动画讲解视频，可在网页里观看，也可以下载 MP4。

## 一、在自己电脑上使用

### 需要先装好的软件

| 软件 | macOS | Windows |
| --- | --- | --- |
| Node.js 20 以上 | `brew install node` | <https://nodejs.org> 下载 LTS 版 |
| Python 3.9 以上 | `brew install python` | <https://www.python.org/downloads/>，安装时勾选 Add python.exe to PATH |
| ffmpeg | `brew install ffmpeg` | `winget install Gyan.FFmpeg` |
| Chrome 或 Edge 浏览器 | 一般已有 | 一般已有 |

缺哪个，启动时窗口里会提示。

### 启动

- macOS：双击 `启动网站.command`。第一次如果提示“无法打开”，请右键点它，选“打开”。
- Windows：双击 `start-windows.bat`。
- 第一次启动会联网准备配音组件，网络慢时要等几分钟。之后浏览器会自动打开 <http://127.0.0.1:5178>。
- 关闭启动窗口，网站就停止。

### 使用

1. 点右上角「AI 模型配置」：选择模型服务，填写 API Key 和模型名称，点「测试连接」，再「保存并使用」。
2. 提供题目（粘贴文字、上传截图、填写链接，可以同时提供），在右侧粘贴答案代码。
3. 选择讲解角色（可以上传自己的图片）、配音、学生年龄、时长和场景。
4. 点「生成讲解视频」。完成后可以在线观看，下载视频、字幕和分镜。
5. 需要分享视频时，点「上传到 NOS 获取分享链接」（只在有道内网可用，只在点击时上传）。

不想先配置模型，可以点「不配置模型，先用示例试一试」，它使用内置的《排队接水》分镜，不调用 AI。

## 二、让同事直接用浏览器访问（局域网共享）

只需要一台电脑装好环境，其他人不用装任何东西。

1. 在这台电脑上双击 `启动网站-局域网共享.command`（Windows 是 `start-windows-lan.bat`）。
2. 按提示设置一个访问密码。
3. 窗口里会显示形如 `http://10.x.x.x:5178` 的地址，把地址和密码发给同事。

注意：

- 系统防火墙要允许 node 接受传入连接：macOS 会弹窗询问，点“允许”；没有弹窗时到“系统设置 → 网络 → 防火墙 → 选项”里添加 node。
- 这台电脑要一直开着，窗口不能关。
- 所有人共用这台电脑上配置的 AI 模型和 API Key，费用算在这个 Key 上。
- 所有人看到的是同一份视频列表，任何人都能删除视频、修改模型配置。
- 一次只生成一个视频，其他人的任务会排队。

## 三、部署到服务器（在线网站）

项目里带了 `Dockerfile` 和 `docker-compose.yml`。在装有 Docker 的 Linux 服务器上：

```bash
cp .env.example .env      # 编辑 .env，填写 ACCESS_PASSWORD
docker compose up -d --build
```

然后访问 `http://服务器地址:5178`。数据保存在项目下的 `data/` 目录。

说明：

- 这套部署文件还没有在真实服务器上跑过，第一次部署可能需要调整。
- Linux 上的字体和 macOS 不同，画面文字的样子会有差别。
- 对外网开放时请在前面加一层 HTTPS（例如 Nginx 或 Caddy 反向代理）。
- 没有用户账号体系，只有一个共用的访问密码。

## 工作原理

1. AI 模型根据题目和代码写出“分镜 JSON”：每句旁白，以及这句话播放时画面上的动作。
2. edge-tts 给每句旁白配音，按真实音频时长生成时间轴和字幕。
3. 播放器（`player/`）按分镜逐帧画出动画，Chrome 无头模式截图。
4. ffmpeg 把画面和配音合成 MP4。

画面由固定的控件组成：数组 / 队列 / 栈、网格（迷宫、二维表）、图 / 树、变量、代码编辑器、输入输出、文字。
AI 只决定“放哪些控件、每句话做什么动作”，不直接写画面代码。

## 目录

| 路径 | 内容 |
| --- | --- |
| `server.js` | 网站服务和接口 |
| `scripts/start.js` | 启动器：检查环境、准备配音组件、启动服务 |
| `scripts/make_package.sh` | 打包成可分发的压缩包（不含 API Key 和已生成的视频） |
| `lib/llm.js` | 模型服务预置和调用 |
| `lib/storyboard.js` | 给模型的提示词、分镜校验 |
| `lib/pipeline.js` | 任务流水线（分镜 → 配音 → 渲染 → 合成） |
| `lib/voice.py` | 配音、时间轴、字幕 |
| `lib/render.js` | 逐帧渲染 |
| `lib/nos.js` | 上传视频到有道 NOS |
| `player/` | 动画播放器和各种控件 |
| `public/` | 网页 |
| `builtin/` | 内置角色和示例 |
| `data/` | 运行后产生：模型配置、上传的角色、生成的视频 |

## 注意

- API Key 以明文保存在 `data/config.json`。把项目发给别人时请用 `scripts/make_package.sh` 打包，它不会带上 `data/`。
- 配音使用微软 edge-tts 在线服务，生成时需要联网。
- 演示数据的每一步数值由 AI 手算，可能出错。发现问题可以在结果页修改分镜后重新生成。
- 上传到 NOS 的视频，拿到链接的人都能观看，文件会一直保留，网站里无法删除。
- 环境变量：`PORT`（端口，默认 5178）、`HOST`（默认 127.0.0.1）、`ACCESS_PASSWORD`（访问密码，HOST 不是本机时必填）、`CHROME_PATH`（指定浏览器程序）。
